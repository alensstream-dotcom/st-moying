# 小说阅读器 v6.3 / 墨影 0.1.24

在酒馆扩展管理中更新墨影并刷新页面，再导入本目录的 `novel-reader-v6.3.json`。停用旧小说脚本，避免两份队列同时运行。

阅读器通过 `STBaiBaiImage.novelReader` v1 工作：逐楼分析正文，校验并保存 tag 与人物/服装增量，然后立即分析下一楼。图片任务独立完成，仍经过墨影原有 NovelAI 并发闸门和限流退避。最多前瞻 3 个待出图楼层。

后台分析不等待编辑框、楼层 DOM、消息渲染事件或绘制帧。图片完成后按聊天、消息身份、swipe 和 tag 校验写入原有 `extra.bbiImage`，保留现有卡片与导出格式。返回前台后补挂阅读窗口并刷新显示。

已有有效 tag 的楼层会直接复用；图片失败后重试图片，不重复调用 LLM。LLM 明确判断无需配图时保存该决定。停止队列会停止提交新楼，已提交任务继续完成保存。可用“恢复待处理”续跑。

如仍失败，在“批量选择与分节设置”中点击“导出队列诊断”。报告记录接口版本、每楼 tag 与图片的阶段和失败理由，不主动采集 Key 或小说正文。插件返回的错误信息会出现在报告中，发送前可自行查看。

本版保留墨影已有的素材库、人物/服装状态、预设与后台恢复功能，没有用公开上游整体覆盖。Android 系统完全冻结 WebView 或杀进程时，仍需返回应用后恢复任务。尚未在用户的真实手机和 NovelAI 服务上验证。
